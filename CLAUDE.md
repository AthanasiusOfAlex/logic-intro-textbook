# Logic Intro Textbook

This project is an introductory textbook on Logic, maintained in three parallel languages:

- English
- Spanish
- Italian

## Footnote Markers

In the trilingual logic textbook (English/Italian/Spanish parallel translations):

- **English**: footnote markers go *after* the period — e.g. `science of reason.[^arsquaedam]`
- **Italian**: footnote markers go *before* the period — e.g. `della ragione[^arsquaedam].`
- **Spanish**: footnote markers go *before* the period — e.g. `ciencia racional*[^arsquaedam].`

**Why:** This follows the typographic conventions of each language (Anglophone style places the superscript after punctuation; Italian and Spanish academic style places it before).

**How to apply:** When proofreading or editing footnotes across the three parallel `md/en/`, `md/it/`, `md/sp/` files, do NOT "fix" the inconsistency between languages — it is intentional. Only flag inconsistencies *within* the same language file.
